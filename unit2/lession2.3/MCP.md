### 客户端和服务端的4种交互方式


| 对比维度 | STDIO | Streamable HTTP | SSE | In-Process |
| -------- | -------- | -------- | --- | --- |
| 通信方式 | 标准输入输出管道  | HTTP 请求与响应 | HTTP 事件流 |  进程内直接通信 |
| 是否需要网络端口 | 否  | 是  | 是  | 否 |
| 是否需要独立服务进程 | 通常需要  | 服务端独立运行  | 服务端独立运行 | 不需要 |
| 适合场景 | 本地工具  | 远程服务 | 实时事件推送 | 嵌入式集成、测试  |
| 网络部署 | 不适合直接远程连接  | 适合 | 适合 | 不适合直接远程连接  |


### Prompts、Tools、Resources 有什么区别？
这是mcp最值得理解的3个概念。

| 能力 | 主要作用 | 例子 |
| -------- | -------- | -------- |
| Tools  | 执行操作或计算  | 查询数据库、调用 API、创建文件  |
| Prompts  | Resources  | 代码审查模板、报告生成模板 |
| Resources  | 向 AI 应用提供数据或内容  |文档、配置文件、数据库中的资料  |

### 身份识别与鉴权等
一般有2种情况

#### 自己做的vue客户端或者应用程序客户端

方案一：后台页面创建token，进行配置到客户端里。之后客户端请求mcp服务端tool时，通过环境变量获取token即可。

方案二：可以新增登录按钮自行引导登录，登录后有个token，之后调用mcp服务端tool时可以带上这个token。
